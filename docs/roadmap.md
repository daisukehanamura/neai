## 次にやること

### 実機で確かめる（家の静かな環境で）

1. **ウェイクワードの語の比較。** クラピカ / ハンターハンター / 幻影旅団 を各5回。
   設定画面で切り替えられる
2. **コンプレッサの効果。** ゲインを6倍に戻して ON/OFF を比較。
   効けばゲインを下げられる
3. **離れた位置での入力レベル（dBFS）。** 外付けマイクの要否はこれで判断する
4. **アラーム音がマナースイッチで消音されないか。** アラームとしては致命的
5. **発話テキストがテキスト出力として課金されるか**（画面のトークン内訳を見る）

`spike/vosk.html` は認識結果の生テキストが見えるので、語の比較にはこちらが向く。

### 第5段階：認証とデプロイ

**今は Mac の開発サーバー依存で、閉じると使えない。** 常設端末として実用にするには
これが要る。ただし公開する以上 `DEVICE_KEY` による認証が必須。

**Vosk のモデル（48MB）は Cloudflare Workers の静的アセット上限（25MB）を超える。**
R2 等に置く必要がある。`VITE_WAKEWORD_MODEL` で差し替えられるようにしてある。

### 構造化した画面出力

発話テキストの表示は入れたが、天気やレシピは表形式や手順リストのほうが読みやすい。
音声レスポンスの後に `output_modalities: ["text"]` の応答を追加する案が有力
（音声のレイテンシに影響しない）。1往復あたり1円弱の追加になる見込み。

### ローカルコマンド層

Vosk は全文認識なので、**ウェイクワード用に常時回している認識結果を
そのままローカルコマンドの照合に使える。** 「タイマー3分」「止めて」「今何時」を
OpenAI に繋がずに実行できる。追加コストはほぼゼロ。

語彙表に「タイマー」「一〜十」「分」「止めて」「今」「何時」があることは確認済み。

念能力の用語が機能名にそのまま対応するのも分かっている
（円＝周囲を見る、凝＝詳しく見る、絶＝待機解除）が、
**1〜2モーラなので認識には向かない。** 会話中のコマンドとしてなら可能性はある。
