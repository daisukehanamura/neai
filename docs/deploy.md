# デプロイ手順

Cloudflare Workers へ公開して、Mac が無くても動く状態にする。

**ローカル開発の手順は一切変わらない。** 本番だけで有効になる仕組み
（デバイスキー、モデルの分割配信）を足してあり、ローカルでは
設定しなければ従来どおり動く。

## 費用

**Cloudflare 側はゼロ。** 無料プランで足りる。

| 項目 | 無料枠 | この用途 |
|---|---|---|
| リクエスト | 10万/日 | 静的ファイルの配信は対象外なので、まず届かない |
| 静的アセット | 2万ファイル、1ファイル25MiB | モデルを分割して3ファイル |
| Worker のサイズ | 圧縮後3MB | 数十KB |

**アカウント作成にクレジットカードは不要。** 増える費用は OpenAI だけで、
これはローカルで動かしていたときと変わらない。

## 手順

### 1. アカウントと認証（あなた / 約10分）

1. https://dash.cloudflare.com/sign-up でアカウントを作る（メールのみ）
2. 認証する

```bash
npx wrangler login
```

ブラウザが開くので許可する。

### 2. モデルを分割する（1分）

```bash
npm run model
```

Cloudflare の静的アセットは**1ファイル 25MiB が上限**なので、48MB のモデルを
20MB ずつに分けて `public/wakeword/` へ置く。`manifest.json` も一緒に作られる。

クライアントは manifest を見て順に取得し、繋ぎ直してから使う。
**ローカルでも同じ経路を通る**ので、本番でだけ動かないということが起きない。

### 3. デバイスキーを作る（2分）

```bash
npm run newkey
```

生成されたキーを控えて、次に進む。

### 4. Secrets を登録する（3分）

```bash
npx wrangler secret put OPENAI_API_KEY   # .dev.vars と同じ値
npx wrangler secret put DEVICE_KEY       # 手順3で作ったキー
```

**`DEVICE_KEY` を設定せずに公開しないこと。** 誰でもあなたの課金で
AI と会話できてしまう。Worker はこれが設定されているときだけ認証を要求する。

### 5. デプロイする（2分）

```bash
npm run deploy
```

`https://neai.<あなたのアカウント>.workers.dev` が払い出される。

### 6. iPhone で開く（1分）

**初回だけ**キー付きの URL で開く。

```
https://neai.xxx.workers.dev/#k=<手順3のキー>
```

端末に保存され、URL からは自動で消える。以後は普通の URL で使える。
設定画面の「デバイスキー」で保存されたことを確認できる。

## デプロイ後に変わること

- **Mac が不要になる。** 開発サーバーを起動しておく必要がなくなる
- **自己署名証明書と警告画面が消える。** 正式な HTTPS になる
- **家の外からも使える。** 反面、URL は誰でも叩ける状態になる

## 残っている宿題

**1日あたりの利用上限が無い。** キーが漏れた場合、OpenAI の Usage limits に
達するまで使われ続ける。Workers KV で日次のセッション数を数えて止めるのが
本筋だが、KV の名前空間を作る必要があるためデプロイ後に対応する。

それまでは **OpenAI 側の Usage limits を必ず設定しておくこと。**

## ローカルに戻るとき

何も変えなくてよい。

```bash
npm run dev
npm run proxy
```

`.dev.vars` に `DEVICE_KEY` を書いていなければ認証は要求されない。
モデルも分割されたものをそのまま使う。
