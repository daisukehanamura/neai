## vosk.html — ウェイクワード検証

事前に `./scripts/fetch-vosk-model.sh` でモデル（約48MB）を取得しておく。

1. 「モデルを読み込む」→ 2.「マイクを開始」→「ねえエーアイ」と話しかける

**文法限定にチェックを入れると精度が上がる。** 認識対象を数語句に絞るため。
`[unk]` は消さないこと。無いと無関係な音まで誤検出する。

調整の順番：

1. 文法限定 ON で検出できるか
2. 届く最小のゲインを探る（初期の10倍は雑音も増幅する）
3. 離れた位置での入力レベルを記録 → 外付けマイクの要否を判断

## phase0.html — 第0段階：実機検証

コードを書く前に、iPhone XR 実機で三つの前提を確かめる。
ここで①が落ちると第2段階（画像質問）の設計が変わるので、先に潰す。

OpenAI にはまだ繋がない。**この段階の課金はゼロ**。

## 手順

```
node spike/serve.mjs
```

表示された `https://192.168.2.200:8443/` を **iPhone の Safari** で開く。
自己署名証明書なので警告が出るので、
「詳細を表示」→「この Web サイトを閲覧」→「Web サイトを閲覧」と進む。

Mac と iPhone が同じ Wi-Fi にいること。ページ内のボタンを上から順に押していく。

## 判定基準

### ① マイクとカメラの同時保持

**必ず A → B → C の順に押すこと。** C は映像を壊すので最後。

| ボタン | 見るところ | 合格 |
|---|---|---|
| A. 一括取得 | 音声・映像トラック、レベルメーター | 両方 `live`、話すとメーターが振れる |
| B. フレームを1枚取り出す | 取得時間とサイズ | 数十ms、100〜300KB程度 |
| C. あとからカメラを単独取得 | 0.5/2/5秒後の記録 | **音声**が `live` のまま、話せばレベルが振れる |

**C で見るのは音声の生存だけ。** iOSは同時に1つのカメラしか掴めないため、
1本目の映像トラックが `ended` になるのは想定内（2026-08-29 に確認済み）。
音声まで死ぬ場合は、通話中にカメラを触る操作を一切禁止する必要がある。

「生きているが無音」と出たら、**実際に話しかけて**メーターが振れるか確認すること。
無音判定は環境音の静けさでも出るため、それだけでは断定できない。

### ② エコーキャンセル

**先に「まず440Hzを鳴らす」で音が聞こえるか確かめる。** 聞こえなければ計測しても無意味。
そのうえで `AECあり` と `AECなし` を**両方**実行する。片方だけでは
「AECが効いた」のか「そもそも音が届いていない」のか区別できない。

iPhoneの音量は実運用と同じくらいまで上げておくこと。

- 差分 6dB 未満 … 良好。スピーカーの音を拾っていない
- 6〜15dB … 音量とマイク距離の調整が要る
- 15dB 以上 … AI が自分の声で割り込む恐れがある。設置方法の見直しが必要

「実際」の欄が要求値と食い違う場合、iOS が設定を上書きしている。
そのときは `AECなし` の計測自体が成立していないので、値ではなく食い違いの事実を記録する。

音の聞こえ方も記録する。iOS はマイク取得中に出力先が受話口へ切り替わることがあり、
常設端末の音量設計に直結する。

### ③ 画面スリープ防止と長時間安定性

`長時間監視を開始` を押し、**給電したまま数時間放置**する。
30秒ごとに記録が残るので、あとから見れば何がいつ落ちたかがわかる。

- Wake Lock が「保持中」のままで、画面が消えない
- 定期記録に赤い行（トラック死亡 / Wake Lock 解放）が出ない
- ホーム画面に出して戻したとき、Wake Lock が自動復帰する

最後に「コピー」でログを取り出して残す。

## 結果を受けた分岐

| 結果 | 次の手 |
|---|---|
| 三つとも合格 | 第1段階へ。設計変更なし |
| Cで映像だけ死ぬ | 想定内。一括取得を保持し続け、カメラを取り直さない方式で第1段階へ |
| Cで音声も死ぬ | 通話中のカメラ操作を全面禁止。第2段階の作りを見直す |
| ①の一括取得が不合格 | カメラと音声を同時に扱えない。第2段階を「会話を一旦切って撮影」に作り替える |
| ②が15dB以上 | 設置方法（マイク距離・音量・外部スピーカー）を先に詰める |
| ③でWake Lockが保てない | 常設運用の方法を見直す（アクセスガイド等） |
